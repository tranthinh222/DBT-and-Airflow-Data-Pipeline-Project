## Lab 4: Intermediate Transformations (45 minutes)

### Objective
Create intermediate models that apply business logic.

### Steps

#### 4.1 Create Customer Metrics Model

**File:** `dbt/models/intermediate/int_customer_metrics.sql`
```sql
{{ config(
    materialized='view',
    schema='intermediate'
) }}

WITH customer_orders AS (
    SELECT
        customer_id,
        order_id,
        order_date,
        total_amount
    FROM {{ ref('stg_orders') }}
)

SELECT
    customer_id,
    COUNT(order_id) as total_orders,
    SUM(total_amount) as lifetime_value,
    AVG(total_amount) as avg_order_value,
    MIN(order_date) as first_order_date,
    MAX(order_date) as last_order_date,
    DATEDIFF(day, MIN(order_date), MAX(order_date)) as customer_tenure_days
FROM customer_orders
GROUP BY customer_id
```

#### 4.2 Create Product Performance Model

**File:** `dbt/models/intermediate/int_product_performance.sql`
```sql
{{ config(
    materialized='view',
    schema='intermediate'
) }}

WITH order_details AS (
    SELECT
        product_id,
        order_id,
        quantity,
        unit_price,
        line_total
    FROM {{ ref('stg_order_details') }}
)

SELECT
    product_id,
    COUNT(DISTINCT order_id) as times_ordered,
    SUM(quantity) as total_quantity_sold,
    SUM(line_total) as total_revenue,
    AVG(unit_price) as avg_selling_price
FROM order_details
GROUP BY product_id
```

#### 4.3 Run All Intermediate Models


## Lab 5: Analytics Marts (60 minutes)

### Objective
Create final analytics tables for business users.

### Steps

#### 5.1 Create Customer Analytics Mart

**File:** `dbt/models/marts/customer_analytics.sql`
```sql
{{ config(
    materialized='table',
    schema='marts'
) }}

WITH customers AS (
    SELECT * FROM {{ ref('stg_customers') }}
),

metrics AS (
    SELECT * FROM {{ ref('int_customer_metrics') }}
)

SELECT
    c.customer_id,
    c.territory_id,
    m.total_orders,
    m.lifetime_value,
    m.avg_order_value,
    m.first_order_date,
    m.last_order_date,
    m.customer_tenure_days,
    CASE
        WHEN m.lifetime_value >= 10000 THEN 'High Value'
        WHEN m.lifetime_value >= 5000 THEN 'Medium Value'
        ELSE 'Low Value'
    END as customer_segment,
    CASE
        WHEN m.customer_tenure_days >= 365 THEN 'Loyal'
        WHEN m.customer_tenure_days >= 180 THEN 'Regular'
        ELSE 'New'
    END as customer_type
FROM customers c
INNER JOIN metrics m ON c.customer_id = m.customer_id
```

#### 5.2 Create Product Analytics Mart

**File:** `dbt/models/marts/product_analytics.sql`
```sql
{{ config(
    materialized='table',
    schema='marts'
) }}

WITH products AS (
    SELECT * FROM {{ ref('stg_products') }}
),

performance AS (
    SELECT * FROM {{ ref('int_product_performance') }}
)

SELECT
    p.product_id,
    p.product_name,
    p.product_number,
    p.color,
    p.list_price,
    COALESCE(pf.times_ordered, 0) as times_ordered,
    COALESCE(pf.total_quantity_sold, 0) as total_quantity_sold,
    COALESCE(pf.total_revenue, 0) as total_revenue,
    COALESCE(pf.avg_selling_price, 0) as avg_selling_price,
    CASE
        WHEN pf.total_revenue >= 100000 THEN 'Top Seller'
        WHEN pf.total_revenue >= 50000 THEN 'Good Seller'
        WHEN pf.total_revenue > 0 THEN 'Low Seller'
        ELSE 'No Sales'
    END as product_performance
FROM products p
LEFT JOIN performance pf ON p.product_id = pf.product_id
```

#### 5.3 Run All Models

```bash
docker-compose exec dbt dbt run
```

#### 5.4 Verify Results

```sql
    COUNT(*) as product_count,
    SUM(total_revenue) as total_revenue
```

## Lab 7: Airflow Orchestration (45 minutes)

### Objective
Schedule and monitor DBT runs using Airflow.

### Steps

#### 7.1 Access Airflow UI

1. Open browser: http://localhost:8080
2. Login:
   - Username: `admin`
   - Password: `admin`

#### 7.2 Explore the DBT DAG

**File:** `airflow/dags/dbt_dag.py`
```python
from airflow import DAG
from airflow.operators.bash import BashOperator
from datetime import datetime, timedelta

default_args = {
    'owner': 'airflow',
    'depends_on_past': False,
    'start_date': datetime(2024, 1, 1),
    'email_on_failure': False,
    'email_on_retry': False,
    'retries': 1,
    'retry_delay': timedelta(minutes=5),
}

dag = DAG(
    'dbt_transform',
    default_args=default_args,
    description='Run DBT transformations',
    schedule_interval='@daily',
    catchup=False
)

dbt_run = BashOperator(
    task_id='dbt_run',
    bash_command='cd /opt/airflow/dbt && dbt run',
    dag=dag
)

dbt_test = BashOperator(
    task_id='dbt_test',
    bash_command='cd /opt/airflow/dbt && dbt test',
    dag=dag
)

dbt_run >> dbt_test
```

#### 7.3 Trigger the DAG

1. In Airflow UI, find `dbt_transform` DAG
2. Toggle the DAG to ON
3. Click "Trigger DAG" (play button)
4. Watch the execution in Graph view

#### 7.4 Monitor Execution

**Views to explore:**
- **Graph View:** Task dependencies
- **Tree View:** Historical runs
- **Gantt View:** Task duration
- **Task Logs:** Detailed output

#### 7.5 Check Task Logs

1. Click on a task (e.g., `dbt_run`)
2. Click "Log" button
3. Review DBT output
